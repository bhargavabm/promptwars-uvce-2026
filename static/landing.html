Bankism

Bankism is a defensive AI firewall that screens untrusted banking messages before any transaction runs. Each message is treated as untrusted input and is checked by deterministic rules and an AI classifier before a final decision is issued.

Check a message

How screening works

Every message is first normalized to strip hidden characters, unusual Unicode, and simple encodings such as base64 or hex. Deterministic rules then look for known attack patterns, and an AI classifier reads the message as data rather than instructions. A final merge step produces the decision: rules are authoritative, and the classifier can only make the outcome stricter, never weaker.

What it blocks

Prompt-injection jailbreaks, attempts to override security policy, hidden instructions embedded in payment memos, token obfuscation and encoding tricks, data-exfiltration requests, and unbounded or ambiguous transfers that do not name a specific recipient and amount.

What it approves

Ordinary balance inquiries and bounded peer-to-peer transfers that name a clear recipient and a positive amount within the configured limit.

Bankism — prototype project. This is a demonstration, not a real banking service.
