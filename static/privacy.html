Privacy Notice

This notice explains, in plain language, how the Bankism demonstration handles your information.

What we process

When you submit a message on the "Check a message" page, that text is sent from your browser to the Bankism server and then to Google's Gemini API so it can be screened for threats. The server does not keep the message text.

Third parties

Messages are sent to Google's Gemini API for classification. That is the only third party involved. There is no advertising, tracking, or analytics on this site.

What we do not store

We do not store the text you enter. Screening results are held in memory on the server only for a short time so an identical message can be reused, and they are keyed by a one-way hash rather than by the message itself.

This demonstration has no sign-in. Nothing you type on the profile page is saved, and no account or banking details are stored.

Retention

Messages are not retained. In-memory screening results live only for the life of the server process and are cleared when it restarts.

Your rights

India's Digital Personal Data Protection Act, 2023 governs personal data. Because we do not store your messages or profile, there is generally no stored data to access, correct, or erase. If you have a request, please contact the project author.
